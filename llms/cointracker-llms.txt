# CoinTracker

> CoinTracker is a cryptocurrency portfolio tracker and crypto tax software that syncs wallets and exchanges to calculate cost basis, capital gains, and generate tax reports. Its developer surface is limited to a first-party npm SDK and partner/enterprise integrations; the HTTP API is enterprise/partner-gated and not self-serve documented publicly.

## Notes
- No public OpenAPI/AsyncAPI/GraphQL specification was discoverable.
- No public MCP server, hosted or remote, was found.
- CoinTracker's marketing/docs site (www.cointracker.io) enforces bot protection (HTTP 403 to automated clients), which limited discovery of pricing, documentation, blog, and .well-known surfaces.
